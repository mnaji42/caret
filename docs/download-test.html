Au premier lancement

  1. Glissez Caspr dans le dossier Applications.
  2. macOS refuse : l'app n'est pas notarisée.
  3. Réglages Système › Confidentialité et sécurité › Ouvrir quand même.
  4. Une fenêtre d'accueil s'occupe du reste.

Ce que cette page vérifie

  1. Le dépôt est public et son API répond.
  2. Une release existe et porte un tag.
  3. L'asset s'appelle bien Caspr.dmg.
